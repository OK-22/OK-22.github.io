Ticket triage service

A FastAPI service that sorts IT help desk tickets into six categories and suggests the best-matching knowledge-base article.

Showed
87.5% accuracy (42 of 48) on hand-written tickets kept separate from training. On the template-generated training data it scored 99.9%, which is why the separate set matters. The README lists all six mistakes.
Limit
The training data is synthetic, the test set is small, and article search only matches shared words.

Python, scikit-learn, FastAPI, Docker

Purchase-to-pay process mining

Process mining and an early-warning rule for late purchase-to-pay cases. A design package describes how a production version could work.

Showed
On a simulated log of 20,000 cases, the rule caught 98% of late cases on a held-out 30%, with 31% precision (3.2 times better than picking cases at random).
Limit
The data is simulated, so real performance is unknown, and about two in three alerts were false alarms. The design package is design only.

Python, PM4Py, pandas
